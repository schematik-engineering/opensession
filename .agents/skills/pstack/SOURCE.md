# Source and adaptation

This skill adapts the Poteto Mode methodology from:

- pstack by Lauren Tan and contributors: https://github.com/cursor/plugins/tree/main/pstack
- the Pi-native port by Radical Tinker and contributors: https://github.com/kkgogogo17/pi-pstack

Both source projects are MIT licensed. The local adaptation removes dependencies on Cursor commands and Pi extensions, uses Open Session's policy-gated tools and isolated sessions, and condenses the playbooks around Open Session's repository and deployment rules.

Imported and adapted on 2026-08-28 from `kkgogogo17/pi-pstack` commit `14da130e`.
