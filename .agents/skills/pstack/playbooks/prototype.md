# Prototype

Own the decision, not production code.

1. Name the empirical or product decision the prototype must settle. If there is no decision, use the feature playbook.
2. Build the smallest throwaway instrument in an isolated scratch location. Do not reshape production code to host it.
3. When comparing alternatives, put them behind one labeled switcher or one repeatable command so the same input reaches each option.
4. Observe the deciding evidence. Use screenshots and interaction for visual work, output for behavioral work, and measurements for timing work.
5. Compare tradeoffs and recommend one option. Discard the rest.
6. Hand the chosen outcome to the feature playbook for production implementation.

Report the decision, alternatives, evidence, recommendation, and scratch path. State plainly that the prototype is throwaway.
